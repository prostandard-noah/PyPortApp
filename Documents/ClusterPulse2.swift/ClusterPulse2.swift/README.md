# ClusterPulse

An iOS dashboard app built with Swift and SwiftUI. It lets you keep track of a server cluster. A cluster is a group of networked servers working together as a single system. The app monitors their health, latency, and request traffic in real time. It is a simulation of server cluster performance.

## Core Features
* **Live Server Status:** Instant health checks for healthy, degraded, offline, and recovering nodes.
* **Network Tracer & Latency:** Real-time visualization of network speed and round-trip response times.
* **Traffic Throughput:** Monitors live request volumes moving through the system.
* **Failure Simulation:** Manually trigger server drop-outs and failovers to test system response.

## Tech Stack & Requirements
* **Language & UI:** Swift, SwiftUI
* **Environment:** iOS 17+ / Xcode 15+
