# PyPortApp

An iOS app I built for probability and statistics.

## Why I Built This
I built this app to create a mobile environment for learning probability and statistics, and to explore how code can improve education. I used the textbook *Probability and Statistics for Engineers and Scientists* (4th ed.) by Anthony J. Hayter from my math course to build a mobile tool specifically tailored to the chapters we cover in class. I wanted a clean way to study on the go and keep formulas organized by chapter.

## What it does
* **Curriculum Navigation:** Browse through chapter notes and reference guides right from your phone.
* **Interactive Z-Score Calculator:** Adjust sliders for your observed value, mean, and standard deviation to see live formula calculations instantly.

## Built With
* Swift
* SwiftUI
* Xcode
